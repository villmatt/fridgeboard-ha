Link to your FridgeBoard

On your phone, open FridgeBoard, then Settings › Home Assistant › Link. Type the 6-character code it shows.

What FridgeBoard can use

Tick what FridgeBoard may use: sensors and buttons that do something on FridgeBoard (a door sensor on the lead drawer, a button by the dog food), and lights, switches, scenes, scripts and sensors for the shared screen. Under each one ticked, you can give it its own name and icon on FridgeBoard. Nothing unticked ever leaves this house. Then set up what each one does in the FridgeBoard phone app, under Settings › Home Assistant.

 

From FridgeBoard

Each time something happens on FridgeBoard, it fires fridgeboard_event here. Use it as an automation's trigger, matching on what's below. For example, event_type: fridgeboard_event with event_data: {type: routine_finished, person: Ben}.
